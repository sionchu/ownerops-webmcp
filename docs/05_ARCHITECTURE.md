# 05 — Architecture

## Core principle
One canonical state, one set of domain actions, multiple adapters.

```text
Human UI ───────┐
                │
WebMCP tools ───┼──> Application actions ──> canonical AppState
                │             │
Snapshot import ┘             ├──> deterministic impact/rule calculations
                              ├──> UI render
                              ├──> localStorage persistence
                              └──> snapshot serializer
```

## Recommended stack
- Next.js App Router
- React
- TypeScript
- CSS Modules + CSS custom properties (preferred for controlled visual design)
- `@dnd-kit/core` only if needed for reliable drag/drop
- Vitest or the test runner generated by the chosen baseline
- Playwright only if it can be added without delaying the MVP; otherwise targeted component/domain tests + manual browser verification
- WebMCP imperative API

Do not add a state-management library unless React state becomes demonstrably awkward. A small context/reducer is sufficient for this MVP.

## Layer responsibilities
### `domain/`
Pure/deterministic business logic. No React. No WebMCP. No localStorage.

### `state/`
Owns the canonical AppState and dispatches shared domain/application actions.

### `components/`
Presentation and user interaction. No duplicated business calculations.

### `webmcp/`
Registers tools and translates tool inputs into the same application actions used by UI.

### `snapshot/`
Round-trip serialization/parsing of the canonical state subset.

## No duplicate logic rule
If `preview staffing change` works in UI and WebMCP, both must call the same function/action. Never copy calculation code into a tool handler.

## Persistence
- App boots from valid `localStorage` state if present.
- Demo reset restores canonical fixture.
- Parse failures must not corrupt current state.

## Deployment
- Local development first.
- Private GitHub remote during build.
- Public live URL for judging.
- Before Devpost submission, make repository public and ensure `LICENSE` is detected.
